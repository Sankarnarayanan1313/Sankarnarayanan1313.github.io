MB Framework

A personal equity-research pipeline for the Indian market, and the backup helper that keeps its data recoverable.

What this application is

MB Framework is a private, single-user system that collects and analyses public market data for Indian listed companies — company fundamentals, corporate-action filings and daily price history. It runs unattended on one server belonging to its author. It is not a product, it is not offered to other people, and it has no users other than its author.

Why it asks for Google Drive access

The framework's data lives on a single machine. If that machine is lost, so is several years of collected market history that cannot be re-fetched from its original sources. So the framework takes scheduled backups and copies them off the machine.

Google Drive is that offsite destination. The application uses the Google Drive API, through rclone, to do three things and nothing else:

  • create a single folder named MB_Framework_Backups in the author's own Drive;
  • upload compressed backup archives into that folder;
  • list and delete its own older archives, so that the retention limit is respected.

The data flows one way — from the author's server into the author's own Drive. Nothing is read from Drive during normal operation, and nothing is sent anywhere else.

Who can use it

One person: the account owner. The OAuth client exists so that the author's own server can write to the author's own Google Drive. There is no sign-up, no shared instance, and no mechanism by which another person's data could reach it.

Privacy

The application collects no personal information, stores nothing about anyone, and shares no data with third parties. This is set out in full in the Privacy Policy.
